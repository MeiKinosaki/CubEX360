# Tela de abertura e áudio

O frontend planejado mostrará uma tela original inspirada na apresentação do console: fundo escuro, logotipo/identidade CubEX360 e animação de entrada, seguida da biblioteca de capas. Para o áudio, implemente futuramente um ponto de configuração para um arquivo fornecido pelo usuário e usado legalmente.

Não incluir a música tema oficial do Nintendo GameCube nem copiar o vídeo/áudio original neste repositório. O runtime atual ainda não implementa reprodução de áudio ou tela de abertura no Xbox 360.
